PART A: Logic Simplification & Basic Digital Gate Realization

2 Design a 4-bit Full Adder and Subtractor circuit and simulate the same using basic logic gates and XOR control line ($M$). Combinational Circuit
PART B: Verilog HDL Hardware Description & Simulation
3 Design Verilog HDL to implement simple logic circuits using Structural, Data Flow, and Behavioral Modeling styles. Verilog HDL
4 Design Verilog HDL to implement Binary Adder-Subtractor circuits: Half Adder, Full Adder, Half Subtractor, and Full Subtractor. Verilog HDL
5 Design Verilog HDL to implement a 4-bit BCD / Decimal Adder with automatic $+6$ correction logic. Verilog HDL
6 Design Verilog program to implement different types of Multiplexers: 2:1 MUX, 4:1 MUX, and 8:1 MUX. Verilog HDL
7 Design Verilog program to implement different types of De-Multiplexers: 1:2 DEMUX, 1:4 DEMUX, and 1:8 DEMUX. Verilog HDL
